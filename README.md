# Теория аналитических функций. Том I

А. И. Маркушевич. **Начала теории**. Второе издание.
Москва: Наука, 1967.

Книга посвящена аналитическим функциям одного комплексного переменного:
основным понятиям, дифференцируемости, элементарным функциям, интегралам,
степенным рядам, вычетам, обратным и неявным функциям.

Текст содержит исправления опечаток и математических неточностей,
а также редакционные примечания там, где требуется пояснение.
Все содержательные изменения перечислены в отдельном журнале.

Основной PDF и журнал исправлений доступны в
[выпусках](https://github.com/stdcall/markushevich.1/releases/latest).
Соглашения исходников и команды сборки описаны в `CONTRIBUTING.md`.
